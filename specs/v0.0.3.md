# RunWitness v0.0.3 Release Scope

Status: Release candidate contract

v0.0.3 keeps the stable v0.0.2 OpenTelemetry Evidence path and adds the first semantic Finding and quality gate derived from observed runtime behavior.

## Stable public surface inherited from v0.0.2

All v0.0.2 behavior remains compatible except for the expected version string moving to v0.0.3.

This includes:

- universal Run boundaries and UUIDv7 Run identity;
- stdout/stderr and process outcome capture;
- Git before/after state;
- `runwitness run --otel -- <command>`;
- Run-owned external `otlp-mcp` lifecycle;
- OTLP exporter environment injection;
- `runwitness.run_id` correlation;
- Evidence v1 JSONL records for spans, logs, and metrics;
- deterministic adapter error semantics;
- the real upstream `otlp-mcp` interoperability gate.

## New stable surface in v0.0.3

The first built-in semantic runtime rule becomes stable:

```text
otel.span status=ERROR
        ↓
runtime.error Finding
        ↓
runtime.no_errors gate
        ↓
verdict fail
```

The stable contract is defined by `specs/runtime-error-v0.0.3.md` and includes:

- one `runtime.error` Finding for each normalized error span;
- `rule_id = otel.span.error`;
- Evidence references from Findings back to `evidence.jsonl`;
- `summary.finding_count` matching the emitted Findings;
- a deterministic `runtime.no_errors` fail gate;
- preservation of the target process exit code independently from the Run verdict;
- CLI exit `1` when a successful target process violates the runtime error gate;
- RunWitness/adapter failures continuing to take precedence as verdict `error`.

## Version contract

The stable release reports:

```text
RunWitness v0.0.3
```

`--version` remains side-effect free and MUST NOT create a Run.

## Explicitly deferred

v0.0.3 does not add:

- error-log or exception-event Findings;
- N+1 or query-performance Findings;
- configurable gate policy;
- baselines or Run diffing;
- Ruby/Rails auto-instrumentation;
- browser correlation;
- PostgreSQL analysis;
- a public RunWitness MCP server;
- production correlation.

## Release gates

A v0.0.3 tag is eligible only when:

1. all locked acceptance tests pass;
2. all v0.0.1 and v0.0.2 compatibility behavior remains green except the intentionally advanced version string;
3. the runtime error Finding acceptance contract passes without modification in the release implementation PR;
4. `go test ./...`, `go test -race ./...`, `go vet ./...`, and gofmt checks pass;
5. the Runner cross-compiles for the established release matrix;
6. the pinned real upstream `tobert/otlp-mcp` interoperability job passes;
7. README and CHANGELOG describe Findings, gates, and the process-status/verdict distinction accurately;
8. `runwitness --version` reports exactly `RunWitness v0.0.3`.
