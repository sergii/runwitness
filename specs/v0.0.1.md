# RunWitness v0.0.1 Release Scope

Status: Stable

v0.0.1 stabilizes the universal Runner core. It is intentionally smaller than the long-term architecture described in `specs/runner.md`.

## Stable public surface

The following behavior is part of the v0.0.1 compatibility contract:

- `runwitness --version`
- `runwitness run [--label <name>] -- <command> [args...]`
- UUIDv7 Run identity
- `RUNWITNESS_RUN_ID` propagation to the target process
- exact target argv preservation
- separate stdout and stderr capture
- process exit status and deterministic verdict mapping
- schema-valid `run.json`
- `evidence.jsonl` artifact reservation
- Git repository state before and after execution
- complete Git working-state fingerprint for tracked and untracked non-ignored files
- exclusion of `.runwitness/` observer-owned artifacts from Git state
- filesystem-only storage under `.runwitness/runs/<run_id>/`

## Stable verdict mapping

```text
0 = pass or warn
1 = fail
2 = RunWitness or CLI error
```

A target that cannot be started produces a Run with verdict `error` and a null target exit code.

## Explicitly deferred

The following are not part of the stable v0.0.1 surface even where the broader architecture documents discuss them:

- `--baseline`
- automatic or explicit Run diffing
- OpenTelemetry ingestion
- Ruby/Rails adapter
- findings engine
- quality-gate configuration
- MCP
- browser evidence
- PostgreSQL analysis
- long-running server correlation

They require their own contract-first slices after v0.0.1.

## Release gates

A v0.0.1 tag is eligible only when:

1. all locked acceptance tests pass;
2. `go test ./...` passes;
3. `go test -race ./...` passes on Linux;
4. `go vet ./...` passes;
5. all Go files are `gofmt` clean;
6. the Runner cross-compiles for Linux, macOS, and Windows on amd64 plus Linux/macOS arm64;
7. README examples match the locked CLI contract;
8. `runwitness --version` reports `v0.0.1`.

All release gates have been satisfied on `main`. The stable core can now be tagged as `v0.0.1` without changing its compatibility contract.

The JSON Schema remains draft until the evidence/findings layers are exercised by real adapters. The fields already emitted by v0.0.1 are nevertheless covered by acceptance tests.
